# 画面設計標準（例示用の抜粋）

この文書は、[`sample-extracted-rules.csv`](sample-extracted-rules.csv) と
[`sample-checklist.csv`](sample-checklist.csv) の入力。
成果物の各行が、この原文のどこから来たかを突き合わせられるようにしてある。

## 3 画面設計書の記述

### 3.2 項目定義

- 項目定義表には項目ID、項目名称、データ型、桁数を記載すること。
- 項目の初期値を定義すること。ただし、参照専用項目の初期値は定義を省略できる。
- 日付項目は YYYY/MM/DD または YYYYMMDD の形式とすること。
- 主要な操作ボタンは画面下部に配置することを推奨する。

### 3.4 入力チェック

- 必須項目は識別可能な表示を行い、未入力の場合はエラー表示すること。

## 5 セキュリティ

- パスワードを画面遷移のURLパラメータに含めてはならない。

## 7 その他

- 画面設計は適切な粒度で行うこと。
