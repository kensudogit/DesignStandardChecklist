## セルフチェック（作成者が Merge Request を出す前に確認する）

CHECKLIST.md より。NG がある状態では Merge Request を出さない。

### 作業開始・実装

- [ ] main を最新化してから作業ブランチを作成した
- [ ] ブランチ名が命名規則に従っている（`feature/` `fix/` `bugfix/` `hotfix/` `refactor/` `docs/` `test/`）
- [ ] main へ直接 Commit していない
- [ ] Issue の範囲内の変更になっている
- [ ] 無関係なファイル変更がない（不要なフォーマット変更を含む）
- [ ] デバッグコードが残っていない
- [ ] Secret情報（APIキー・パスワード・トークン・接続文字列）が含まれていない

### Commit 前

- [ ] `git status` と `git diff` を確認した
- [ ] 単体テストを実行した
- [ ] ビルドが成功した
- [ ] Lint / 静的解析を実行した
- [ ] Commit メッセージが変更内容を表している（`feat:` `fix:` `refactor:` `test:` `docs:` `build:` `ci:` `chore:`）

### Merge 条件

- [ ] CI が成功している
- [ ] Conflict が解消されている
- [ ] 未解決コメントがない
- [ ] 必要な Approval を取得した
